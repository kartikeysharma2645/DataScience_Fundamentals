# DataScience_Fundamentals

A practical assessment covering core Data Science, Python, statistics, data manipulation, and basic data analysis.

## Topics Covered

- Data Science lifecycle and types of data analysis
- Python programming fundamentals
- Statistical foundations
- Data types and structures
- Data manipulation with Pandas
- Basic data analysis and visualization
- Correlation and statistical interpretation
- Data cleaning and missing-value handling

## Project Structure

    DataScience_Fundamentals/
    ├── data/
    │   ├── sample_data.txt
    │   └── cleaned_data.csv
    ├── notebooks/
    │   └── data_science_fundamentals.ipynb
    ├── README.md
    └── requirements.txt

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset

The project uses a small sample customer dataset containing information such as age, course, city, purchase, and rating.

The dataset includes missing values to demonstrate basic data cleaning and handling techniques.

## Analysis Performed

The notebook demonstrates:

- Descriptive statistics
- Frequency analysis
- Filtering and sorting
- Missing-value treatment
- Grouping and aggregation
- Correlation analysis
- Data visualization
- Basic analytical interpretation

## Limitations

The analysis uses a small sample dataset and may not represent a larger population. Mean-based imputation and correlation results should therefore be interpreted within the context of the available data.
